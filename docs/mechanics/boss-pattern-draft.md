# 행방불명 기믹 초안

이 문서는 사용자가 구두로 설명한 보스 기믹을 시뮬레이터 구현용 명세로 정리한 초안이다.

아직 실제 JSON 패턴 파일이 아니라, 기믹 구조와 누락 정보를 확인하기 위한 마크다운 정리본이다.

## 기본 전제

- 기믹 이름은 `행방불명`이다.
- 보스는 항상 아레나 중앙에 위치한다.
- 보스 히트박스는 지름 8m다.
- 보스 히트박스 반지름은 4m다.
- 현재 아레나는 원형 맵이다.
- A 웨이마크 위치를 북쪽 기준으로 본다.
- 탑은 8방향 중 하나에 생성될 수 있다.
  - 북
  - 북동
  - 동
  - 남동
  - 남
  - 남서
  - 서
  - 북서

## 전체 기믹 흐름

```txt
광역 공격 및 1차 머리징 부여 + 1번 탑 즉시 등장
1번 탑 처리
2번 탑 처리 + 미래/과거 캐스팅 확인
3번 탑 등장 + 분신 발차기 유도 + 3번 탑 처리
4번 탑 처리 + 미래/과거 캐스팅 확인
5번 탑 등장 + 분신 발차기 유도 + 5번 탑 처리
6번 탑 처리 + 미래/과거 캐스팅 확인
7번 탑 등장 + 분신 발차기 유도 + 7번 탑 처리
8번 탑 처리 + 미래/과거 캐스팅 확인
8번 탑 종료 후 마지막 분신 발차기 유도 및 안전지대 이동
```

## 1. 시작 공격 및 1차 머리징 부여

### 1.1 광역 공격

기믹 시작 시 강력한 데미지 공격이 들어온다.

### 1.2 머리징 종류

8명 전원에게 머리 위 징이 부여된다.

머리징 종류:

- 쉐어징
- 산개징
- 부채꼴징

각 징은 부여 후 5초 동안 표시되고 사라진다.

징 표시만 5초 후 사라진다.

실제 판정용 징 정보는 대상자에게 계속 유지된다.

### 1.3 1차 머리징 부여 규칙

쉐어징은 총 2개다.

쉐어징 부여:

- 탱커/힐러 4인 중 1명에게 쉐어징 1개
- 딜러 4인 중 1명에게 쉐어징 1개

나머지 6명에게는 부채꼴징 3개와 산개징 3개가 부여된다.

나머지 6명의 부여 패턴은 둘 중 하나다.

패턴 A:

- 쉐어징이 없는 탱커/힐러 3명에게 부채꼴징 3개
- 쉐어징이 없는 딜러 3명에게 산개징 3개

패턴 B:

- 쉐어징이 없는 탱커/힐러 3명에게 산개징 3개
- 쉐어징이 없는 딜러 3명에게 부채꼴징 3개

## 2. 탑 생성 규칙

### 2.1 탑 기본 정보

탑은 고리형 장판이다.

- 지름: 5m
- 반지름: 2.5m
- 한 번에 2개 생성
- 두 탑은 서로 90도 간격
- 탑은 생성 후 8초 뒤 작동한다.
- 탑 중심은 중앙에서 10m 거리에 위치한다.
- 탑 등장 시간 간격은 10초다.

### 2.2 첫 탑 생성 위치

첫 탑은 광역 공격 및 1차 머리징 부여 직후 바로 생성된다.

첫 탑은 8방향 중 하나에 생성될 수 있다.

두 탑은 90도 간격이므로 예시는 다음과 같다.

- 북서 + 북동
- 북서 + 남서
- 동 + 남
- 북 + 동

즉, 8방향 중 서로 90도 차이나는 조합이 선택된다.

가능한 90도 조합 중 랜덤 선택으로 해석한다.

## 3. 탑 작동 판정

탑이 작동되는 시점에 각 탑 안에는 정확히 2명만 들어가야 한다.

성공 조건:

- 각 탑 안 인원 = 2명

실패 조건:

- 탑 안 인원이 2명이 아님
- 해당 탑 폭발
- 전멸

탑이 작동될 때, 탑 안에 들어간 사람들의 현재 머리징 공격이 실행된다.

## 4. 머리징 공격 판정

탑 작동 시점에 탑 안에 들어간 대상자의 징 공격이 실행된다.

### 4.1 쉐어징

쉐어징은 대상자 주변 6m 범위의 쉐어 공격이다.

- 6m는 지름이다.
- 반지름은 3m다.

성공 조건:

- 쉐어 범위 안에 정확히 3명이 있어야 한다.

실패 조건:

- 3명이 아님

- 정확히 3명은 쉐어징 대상자 본인을 포함한 3명이다.

### 4.2 산개징

산개징은 1인 대상 5m 범위 공격이다.

- 5m는 지름이다.
- 반지름은 2.5m다.

성공 조건:

- 대상자 혼자 맞아야 한다.

실패 조건:

- 다른 플레이어가 범위 안에 있어 같이 맞음

### 4.3 부채꼴징

부채꼴징은 대상자와 가장 가까운 유저 방향으로 90도 각도의 범위 공격을 발사한다.

- 기준점은 부채꼴징 대상자 위치다.
- 방향은 부채꼴징 대상자와 가장 가까운 대상자 방향이다.
- 사거리는 20m다.
- 각도는 90도다.

성공/실패 조건:

- 각 공격은 반드시 1개만 맞아야 한다.
- 여러 공격이 겹쳐 맞으면 즉사한다.
- 부채꼴징 대상자는 공격의 중심점이므로 자기 부채꼴 범위에 포함되지 않는다.

- 가장 가까운 유저는 부채꼴징 대상자 본인을 제외한 나머지 7명 중 가장 가까운 1명이다.

### 4.4 공격 범위 표시

데미지가 발생할 때 공격 범위가 표시되어야 한다.

표시 대상:

- 쉐어징 범위
- 산개징 범위
- 부채꼴징 범위

공격 범위 표시 정책:

- 공격 범위는 판정 시점에 표시한다.
- 판정 후 1초 동안 남는다.
- 범위 표시는 투명도가 있는 옅은 주황색으로 표시한다.

## 5. 탑 처리 후 머리징 재부여

탑이 작동되고, 탑 안에 있는 대상자의 징 공격이 끝난 뒤 머리징이 새로 부여된다.

대상:

- 방금 탑 안에 들어왔던 4명
- 즉, 2개 탑에 각각 2명씩 들어간 총 4명

표시 시간:

- 5초

### 5.1 재부여 규칙

방금 탑에 들어온 4명의 기존 머리징 구성을 기준으로 다음 머리징이 정해진다.

조건 A:

- 대상자 4명 중 쉐어징이 2개인 경우

재부여:

- 부채꼴징 2개
- 산개징 2개
- 4명에게 랜덤 재지정

조건 B:

- 대상자 4명 중 쉐어징이 2개가 아닌 경우

재부여:

- 부채꼴징 1개
- 산개징 1개
- 쉐어징 2개
- 4명에게 랜덤 재지정

- 재부여된 징은 다음 탑 처리 때 사용된다.

탑에 들어가지 않았던 나머지 4명의 징은 유지된다.

### 5.2 징 부여 횟수 제한

모든 대상자는 징을 최대 4번까지만 부여받을 수 있다.

따라서 어떤 플레이어가 네 번째로 탑에 들어가 탑 처리를 완료했을 경우, 그 플레이어에게는 새 징이 부여되지 않는다.

- 최초 1차 머리징도 징 부여 횟수 제한 4회에 포함된다.

## 6. 탑 반복 규칙

탑 작동과 징 발동이 반복된다.

반복 횟수:

- 총 8번

시간 간격:

- 탑은 10초 간격으로 등장한다.
- 각 탑은 등장 후 8초 뒤 작동한다.
- 따라서 다음 탑은 이전 탑 작동 후 약 2초 뒤 등장하는 구조다.

탑 이동:

- 매 반복마다 탑 위치가 45도 이동한다.
- 이동 방향은 시계 방향 또는 반시계 방향이다.
- 한 번 방향이 정해지면 이후 7번의 재생성 동안 같은 방향으로 45도씩 이동한다.

- 두 탑 모두 같은 방향으로 45도씩 이동한다.
- 45도 이동 후에도 두 탑 간 90도 간격은 유지되는 것으로 해석된다.

## 7. 짝수번 탑과 보스 캐스팅

짝수번 탑이 등장할 때 보스는 다음 중 하나를 5초간 캐스팅한다.

- 미래의 종언
- 과거의 종언

등장 조건:

- 2번 탑 등장
- 4번 탑 등장
- 6번 탑 등장
- 8번 탑 등장

- 미래/과거는 매 짝수 탑마다 랜덤으로 결정된다.
- 같은 값이 연속될 수 있는 것으로 해석한다.
- 짝수번 탑의 미래/과거 캐스팅은 탑 생성과 동시에 시작한다.

## 8. 짝수번 탑 작동 시 분신 소환

짝수번 탑이 작동함과 동시에 보스와 가장 가까운 4인에게 보스의 분신이 소환된다.

동시에 대상자에게 4m 원형 범위 공격이 발생한다.

- 4m는 지름이다.
- 반지름은 2m다.

대상:

- 중심 기준 가장 가까운 4명

효과:

- 각 대상자에게 분신 소환
- 각 대상자 위치에 4m 원형 범위 공격 발생

- 분신은 대상자 위치에 소환된다.

- 가장 가까운 4인 판정은 중심 기준 거리로 계산한다.

## 9. 분신 주시와 소멸의 발차기

소환된 분신은 5초 동안 랜덤한 대상을 주시한다.

주시 종료 시점:

- 주시 대상자가 있던 위치를 향해 `소멸의 발차기`를 5초간 캐스팅한다.

발차기 공격:

- `미래의 종언`이었다면 전방 180도 부채꼴 공격
- `과거의 종언`이었다면 후방 180도 부채꼴 공격

발차기 판정 시간:

- 탑 폭발과 같은 시간

- 분신 4개가 각각 랜덤 대상을 고르는 것으로 해석한다.
- 같은 대상이 여러 분신에게 주시될 수 있다.
- 주시 대상은 8명 전체 중 랜덤으로 해석한다.
- 주시 중에는 분신의 앞 방향을 작은 화살표로 표시한다.
- 분신은 5초 동안 대상을 주시한다.
- 5초가 되는 순간 대상자의 현재 위치를 고정한다.
- 고정된 위치 방향으로 소멸의 발차기를 5초간 캐스팅한다.
- 과거의 종언 후방 공격은 분신 기준 후방 180도인지
- 소멸의 발차기 사거리는 20m다.
- 소멸의 발차기 범위도 판정 후 1초 동안 투명도가 있는 옅은 주황색으로 표시한다.
- 부채꼴 반경/폭 표현 방식
- 분신 발차기와 탑 폭발은 같은 frame에 판정되는 것으로 해석한다.

## 10. 짝수/홀수 탑 운영 흐름

1번 탑을 제외하고는 다음 흐름이 반복된다.

짝수번 탑 처리 중:

- 보스의 미래/과거 캐스팅을 확인한다.

다음 홀수번 탑이 뜰 때:

- 미래/과거에 따른 분신의 발차기 위치를 유도한다.
- 이후 소멸의 발차기가 시전될 때 홀수 탑 처리 위치로 이동한다.

즉, 짝수 탑에서 본 미래/과거 정보가 다음 홀수 탑 처리 중 분신 발차기 안전지대 판단에 영향을 준다.

- 8번 탑 이후에도 8번에서 확인한 미래/과거에 따라 마지막 분신 발차기 유도가 발생한다.
- 마지막 유도 후 안전지대 이동까지가 기믹 종료 조건으로 보인다.

## 시뮬레이터 구현용 이벤트 분해 초안

아래는 이 기믹을 timeline event로 쪼갠 초안이다.

```txt
t=0.0
- raidwide_damage
- assign_initial_markers
- spawn_towers(round=1)

t=8.0
- resolve_towers(round=1)
- resolve_player_markers_for_tower_players(round=1)
- reassign_markers_for_tower_players(round=1)

round=2, t=10.0
- spawn_towers(round=2)
- boss_cast(future_or_past, duration=5)

round=2, t=18.0
- resolve_towers(round=2)
- resolve_player_markers_for_tower_players(round=2)
- spawn_clones_on_nearest_4
- resolve_4m_circle_on_clone_targets
- clone_gaze(duration=5)
- reassign_markers_for_tower_players(round=2)

round=3, t=20.0
- spawn_towers(round=3)

round=3, t=23.0
- clone_lock_kick_direction
- clone_cast_kick(duration=5)

round=3, t=28.0
- resolve_towers(round=3)
- resolve_player_markers_for_tower_players(round=3)
- resolve_clone_kicks
- reassign_markers_for_tower_players(round=3)

round=4~8
- 위 패턴 반복
```

정확한 시간표는 탑 10초 간격, 작동 8초 후 기준으로 구성할 수 있다.

- 재부여 랜덤은 역할군 제약 없는 완전 랜덤이다.
- 쉐어징 6m는 지름이다.
- 쉐어징은 대상자 포함 정확히 3명이다.
- 산개징 5m는 지름이다.
- 부채꼴징의 사거리는 20m다.
- 부채꼴징은 대상자 위치에서 가장 가까운 유저 방향으로 발사된다.
- 부채꼴징의 "가장 가까운 유저"는 본인을 제외한 나머지 7명 기준이다.
- 최초 머리징도 징 부여 횟수 제한 4회에 포함된다.

### 중첩 판정

- 부채꼴, 산개, 쉐어, 발차기 범위 중 2개 이상에 포함되면 중첩 실패다.
- 쉐어징을 3명이 같이 맞을 때, 그 3명은 쉐어 공격 1개를 맞은 것으로 처리한다.
- 같은 사람이 쉐어 범위와 산개 범위를 동시에 맞으면 중첩 실패다.
- 산개 대상자는 자기 산개 공격에 포함된다.
- 쉐어 대상자는 자기 쉐어 공격 인원에 포함된다.
- 부채꼴 대상자는 자기 부채꼴 공격에 포함되지 않는다.

### 분신 정보

- 짝수번 탑 작동과 동시에 중심 기준 가장 가까운 4명에게 분신이 생긴다.
- 분신은 대상자 위치에 생성된다.
- 4m 원형 범위는 지름이다.
- 분신 주시 대상은 8명 전체 랜덤으로 해석한다.
- 같은 대상이 여러 분신에게 주시될 수 있다.
- 분신 주시 중에는 분신의 앞을 표시하는 작은 화살표를 표시한다.
- 분신은 생성 후 5초 동안 대상을 주시한다.
- 5초가 되는 순간 대상자의 현재 위치를 고정하고, 해당 방향으로 발차기 캐스팅을 시작한다.
- 소멸의 발차기 사거리는 20m다.
- 미래/과거에 따른 전방/후방 180도 기준은 분신 facing 기준으로 해석한다.
- 분신 발차기와 탑 폭발은 같은 frame에 판정되는 것으로 해석한다.

### 범위 표시 정보

- 머리징 공격 범위는 판정 후 1초 동안 표시된다.
- 소멸의 발차기 범위는 판정 후 1초 동안 표시된다.
- 표시 색상은 투명도가 있는 옅은 주황색이다.

### 성공/실패 처리

- 실패 시 처리 방식은 유저가 선택한다.
  - 기믹 실패 시 중단
  - 실패 로그만 남기고 계속 진행
- 실패 시 실패 조건에 포함된 대상자를 텍스트로 표시한다.
  - 예: 범위 공격을 2개 이상 맞은 대상자
  - 예: 쉐어 인원 조건 실패에 포함된 대상자
  - 예: 탑 인원 조건 실패에 포함된 대상자
- 성공 기준은 8번 탑과 마지막 분신 발차기까지 모두 통과하는 것으로 해석한다.

## 우선 구현을 위한 단순화 제안

처음 구현할 때는 아래처럼 단순화하는 것을 권장한다.

1. 탑 위치와 회전 방향은 패턴 시작 시 랜덤으로 결정한다.
2. 탑은 중심에서 고정 거리 `towerDistance`에 생성한다.
3. 탑은 매 라운드 45도씩 이동한다.
4. 머리징은 실제 판정 정보로 유지하고, UI 표시만 5초 후 숨긴다.
5. 쉐어/산개/부채꼴 판정부터 구현한다.
6. 분신 패턴은 2차 단계로 구현한다.

분신까지 한 번에 구현하면 상태가 복잡해지므로, 먼저 "8회 탑 + 머리징 재분배"까지 구현하고 이후 짝수 탑 분신 로직을 붙이는 편이 안전하다.
