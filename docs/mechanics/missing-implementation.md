# "행방불명" 기믹 구현 현황

명세 초안: [`boss-pattern-draft.md`](boss-pattern-draft.md)
draft의 "우선 구현 단순화 제안"에 따라 1단계(탑 + 머리징)를 먼저 구현했다.

## 구현 완료 (1단계)

| 영역 | 내용 | 위치 |
|---|---|---|
| 컨트롤 | 기믹 선택 + 시작/중지/재시작 | `GimmickPanel.tsx`, 메시지 `"gimmick"` |
| 엔진 | 타임라인 스케줄러 + 판정(서버 권위) | `apps/server/src/gimmick/GimmickController.ts` |
| 상태 | 탑/공격범위/머리징/보스캐스팅/로그 동기화 | `schemas/*`, `RaidRoomState` |
| 광역+머리징 | 시작 시 광역, 쉐어2/부채꼴3/산개3 (패턴 A·B 랜덤) | `assignInitialMarkers` |
| 탑 | 8회, 중앙 10m·90도 2개, 라운드마다 45도 회전(시/반시계 랜덤), 8초 후 작동, 10초 간격 | `spawnTowers` |
| 탑 판정 | 탑당 정확히 2명 | `resolveRound` |
| 머리징 공격 | 쉐어(6m/3명), 산개(5m/혼자), 부채꼴(가장 가까운 유저 방향 90도·20m) + 중첩(즉사) 판정 | `resolveMarkerAttacks` |
| 범위 표시 | 판정 후 1초, 옅은 주황 (원/부채꼴) | `AoeSchema`, `AoeIndicators.tsx` |
| 머리징 재분배 | 탑 4인 대상 규칙 5.1 + 4회 제한 | `reassignMarkers` |
| 보스 캐스팅 | 짝수 탑마다 미래/과거 랜덤 표시(5초) | `startBossCast`, `Boss.tsx` |
| 결과 | 성공/실패 로그, 종료 시 성공/실패 판정 | `failRound`, `finish` |

## 미구현 (2단계 — 분신)

draft 섹션 8·9. 상태 복잡도가 커서 분리했다. 현재는 짝수 탑 보스 미래/과거 **표시까지만** 구현.

- [ ] 짝수 탑 작동 시 보스 기준 가장 가까운 4인에게 **분신 소환** + 4m 원형 범위 공격
- [ ] 분신 5초 **주시**(랜덤 대상, 앞방향 화살표 표시)
- [ ] 주시 종료 시 대상 위치 고정 → **소멸의 발차기** 5초 캐스팅
- [ ] 미래=전방 180도 / 과거=후방 180도 부채꼴(사거리 20m), 탑 폭발과 동일 frame 판정
- [ ] 마지막(8번) 이후 분신 발차기 유도 + 안전지대 이동까지를 성공 종료 조건으로

## 단순화 / 해석 메모

- 실패 정책은 기본 **"로그만 남기고 계속 진행"**(draft의 선택지 중 하나). 종료 시 한 번이라도 실패가 있으면 `failed`.
- 플레이어가 8명 미만이어도 크래시 없이 동작(있는 인원 기준 best-effort). 정확한 성공 판정은 8인 전제.
- 탑 채움 애니메이션은 클라 로컬 시각 기준(서버 시계 동기화 없음).
- 부채꼴 방향/판정은 이동과 동일한 `atan2(x, z)` 규약 사용.
