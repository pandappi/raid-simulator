## 단순화 / 해석 메모

- 실패 정책은 옵션으로 선택한다. 기본 UI는 **실패시 중단**을 켜고 시작하며, 끄면 로그만 남기고 계속 진행한다.
- 라이브룸의 시작은 빈 역할 자동 보충을 포함한다. 이미 8명이 모두 참여했다면 추가 봇 없이 바로 시작한다.
- 라이브룸 시작은 실제 랜덤 규칙을 사용한다. 보충 봇은 정답 위치를 따라가지만, 머리징/탑 시작 방향/미래과거는 고정 공략보기 패턴을 쓰지 않는다.
- 보충 봇은 첫 머리징 표시 후 1초 동안 초기 6시 대형을 유지한 뒤 움직이기 시작한다.
- 초기 기본 페어는 `MT-H1`, `ST-H2`, `D1-D3`, `D2-D4`다.
- 1조/2조는 최초 머리징 부여 시점에만 결정한다. 쉐어징이 있는 페어는 1조, 쉐어징이 없는 페어는 2조가 되며, 이후 재부여로 머리징이 바뀌어도 조 구성은 바뀌지 않는다.
- 1조는 1, 2, 3, 8번 탑을 처리하고, 2조는 4, 5, 6, 7번 탑을 처리한다.
- `왼쪽탑`/`오른쪽탑`은 월드 X축 기준이 아니라, 두 탑의 가운데에서 보스/중앙을 바라보는 시점 기준이다.
- 같은 머리징 대상자의 좌/우 배정은 각 조가 처음 탑에 들어가는 라운드(1조=1번 탑, 2조=4번 탑)에서는 힐러 → 탱커 → 근딜 → 원딜 순서로 왼쪽을 우선한다. 재지정징이면 현재 처리한 탑 방향을 우선하고, 같은 탑에서 같은 징이 나오면 보스 중심에서 더 먼 대상자가 반대 탑으로 간다.
- 탑 채움 애니메이션은 서버/공략보기 `elapsed` 기준으로 계산하며, 일시정지 시 함께 멈춘다.
- 부채꼴 방향/판정은 이동과 동일한 `atan2(x, z)` 규약 사용.
