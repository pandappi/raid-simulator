# P3 주사위 (`dice`) — 공략보기 명세 / 구현

> 사용자 확정 명세 기반. 공략보기(재생)만 구현(판정·봇 보충 없음).
> 좌표 규약: 북=−Z, `atan2(x, z)`, 8방향 웨이마크 = 중심거리 **13m** 동일.

## 확정 값
- 보스: 8방향 중 랜덤 웨이마크(13m), 지름 10m(반지름 5m). 유저는 보스 안쪽 가장자리(중심거리 8m)에 집결.
- 알테마 블래스터: 폭 8m 직선(`<`는 시각), 외곽→중앙관통→반대끝(1초). 첫 발사 후 2초 간격, 45°씩 회전(시/반시계 랜덤), 총 8발. **#1 시작위치·회전방향 기억**. (회전 단계는 판정 없음/텔레그래프)
- 타임라인: 0s 시작 → 3s #1 → 2s 간격(#8=17s) → 9s(#4) 넉백 5m(보스 기준) → 10s 중앙 6m 연두 장판 집결 쉐어 → 13s(#6) 주사위 1~8 부여 → **22s(#8+5s)** 주사위 유도 시작(1초 간격 1~8).
- 주사위: 1~8, 홀=파랑·짝=빨강 배지.
- 주사위 유도: **#1 시작점**에서 대상자 **방향으로 직선(맵끝까지, 중앙관통 아님)**, 폭 8m. **각자 1대만 = 성공, 2대+ = 실패**.
- 서는 위치: **#1 도착점=12시**. 1번 = 12시에서 회전 반대방향 22.5°. 2~8번 = 직전 기준 회전 반대방향 45°씩 → 웨이마크 사이 맵끝 8곳.

## 구현
- `apps/web/.../scenarios/diceScenario.ts`: 매 판 랜덤 config(보스/시작방향/회전/주사위배정)에서 위치·공격을 **계산**으로 생성(`sampleDice`).
- `useScenarioPlayback(gimmickId="dice")` 분기 → 보스 공격 텔레그래프(직선/연두장판) + 회피 위치 + 주사위 배지 재생.
- 도형: `AoeView` kind `rect`(직선, danger=빨강)·`stack`(연두), `AoeIndicators` 렌더. 주사위 배지: `PlayerSnapshot.dice` + `PlayerLabel`.
- 선택: 로비 "공략 보기 기믹"에서 `P3 주사위` 선택(`GIMMICKS` 레지스트리, `liveSupported:false`).

## 미세 근사/주의
- 타이밍은 확정값(#8+5s 등) 사용. 위치는 키프레임 보간이라 전환 구간은 부드럽게 근사.
- 판정(1대/2대) 로직은 미구현(공략보기 전용). 라이브 판정은 추후.
