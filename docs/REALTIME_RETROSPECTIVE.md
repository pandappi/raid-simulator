# 실시간 동기화 이슈 회고 (원인 / 해결 / 참고)

멀티플레이 이동 동기화를 다듬으며 겪은 문제들을 발생 순서대로 정리한다.
설계 자체는 [`NETCODE.md`](NETCODE.md), 변경 이력은 [`../CHANGELOG.md`](../CHANGELOG.md) 참고.

## 0. 배경 개념 3가지

| 용어 | 뜻 | 왜 필요한가 |
|---|---|---|
| **서버 권위(authority)** | 진짜 위치는 서버가 결정 | 치팅 방지·공정성. 모든 클라가 같은 진실을 봄 |
| **클라 예측(prediction)** | 내 입력 결과를 서버 응답 전에 즉시 화면에 표시 | 네트워크 왕복을 기다리면 조작이 굼뜨게 느껴짐 |
| **보간(interpolation)** | 상대를 약간 과거 시점으로, 스냅샷 사이를 메워 부드럽게 표시 | 서버 업데이트(20Hz)가 띄엄띄엄이라 그대로 그리면 끊김 |

핵심 원칙: **내 캐릭터 = 예측(즉시), 상대 캐릭터 = 보간(약간 과거).**

## 1. 자기 캐릭터가 굼뜸 (최초 증상)

- **원인:** 내 캐릭터조차 서버가 echo한 위치를 `damp`로 따라가기만 함 → 키 입력이 네트워크 왕복만큼 늦게 반영.
- **해결:** 클라이언트 예측 도입(키 누르면 로컬에서 즉시 이동). 이동 계산식을 `packages/shared/stepMovement`로 추출해 서버·클라가 **동일 로직** 공유.

## 2. "따닥" 이중 이동

- **원인:** 예측 위치를 매 프레임 **지연된 서버 위치로 끌어당김**. 예측은 앞서 있는데 서버는 뒤에 있어, 앞으로 갔다 뒤로 당겨졌다 반복(고무줄).
- **해결(중간):** 움직이는 동안엔 예측을 신뢰하고, 정렬은 멈췄을 때만.

## 3. 멈출 때 뒤로 갔다 돌아오는 모션

- **원인:** 멈추는 순간 내 예측은 즉시 정지하지만 서버는 "정지" 신호를 아직 못 받아 따라오는 중. 그 따라오는(뒤쪽) 위치로 정렬이 당김 → 뒤로 끌렸다 복귀.
- **해결(중간):** "나도 멈췄고 + 서버도 멈춘 뒤"에만 정렬하도록 조건 추가.

## 4. 키를 꾹 누르면 주기적 롤백 ← 진짜 원인은 휴리스틱

- **원인:** 위 중간 해결들은 "거리가 일정 이상 벌어지면 스냅" 같은 **임시 휴리스틱**이었음. 계속 이동 시 예측이 서버보다 앞서며 임계치를 넘는 순간 **서버 위치로 스냅(롤백)**.
- **해결(정석):** 휴리스틱 폐기 → **입력 시퀀스 기반 서버 재조정(Server Reconciliation)** 도입.
  1. 모든 입력에 순번 `seq` + 적용시간 `dt` 부여해 전송
  2. 서버는 받은 `dt` 그대로 재현하고, 마지막 처리 순번 `lastSeq`를 echo
  3. 클라는 서버 위치로 맞춘 뒤 **아직 처리 안 된 입력만 다시 적용(replay)**
  - 서버·클라가 같은 함수를 같은 dt로 적용 → 결정론적 일치 → **롤백 없음**.
  - 부수 변경: 서버 이동을 고정 틱 → **입력 명령 기반**으로 전환.

## 5. 멈춘 뒤에도 상대 화면에서 계속 미끄러짐 / 위치 불일치

- **원인:** Colyseus는 **위치가 바뀔 때만** 상태를 보냄. 상대가 멈추면 "정지 위치"가 마지막으로 한 번 오고 업데이트가 끊김. 그런데 보간 코드가 끊긴 구간을 **마지막 속도로 외삽(extrapolation)** → 멈춘 상대를 계속 앞으로 미끄러뜨려(오버슈트) 실제 위치와 어긋남.
- **해결:** 외삽 제거 → 업데이트가 끊기면 **마지막 위치 유지(hold)**. 마지막 패치값이 곧 실제 정지 위치라 hold가 정확.
- **추가:** 창 포커스 상실로 keyup이 누락돼 키가 눌린 채 남는 경우 → `blur` 이벤트에서 입력 강제 해제.

## 남는(정상) 현상

- **움직이는 동안** 상대는 ~70ms + 네트워크만큼 뒤처져 보인다. 이는 보간 지연으로 **모든 온라인 게임 공통**이며 버그가 아니다. **멈추면 정확히 일치**해야 정상.
